# Weather Station with a Web Server in C++ (ESP8266 + DHT11 + LCD 1602)

Цей проєкт реалізує автономну метеостанцію на мікроконтролері **Wemos D1 mini (ESP8266)**. Система збирає дані про температуру та вологість за допомогою датчика **DHT11**, виводить їх у реальному часі на символьний **I2C LCD-дисплей (1602)**, а також запускає вбудований вебсервер для віддаленого моніторингу через локальну мережу Wi-Fi.

---

## 🚀 Основні можливості

* **Неблокуюча архітектура (State Machine)**: Керування станами пристрою (`CONNECTING`, `RUNNING`, `FAILED`) за допомогою `millis()`, що запобігає зависанням програми.
* **Захист від зависання мережі (Timeout)**: Якщо плата не може підключитися до роутера протягом 30 секунд, вона автоматично переходить у стан помилки та перезавантажується (`ESP.restart()`).
* **Автоматичне відновлення зв'язку**: У разі втрати сигналу під час роботи система самостійно намагається перепідключитися.
* **Інформативний I2C-дисплей**: Відображає статус підключення, IP-адресу пристрою, а в штатному режимі — поточну температуру та вологість із захистом від миготіння екрана.
* **Інтегрований вебсервер**: Можливість розширення функціоналу для віддаленого отримання показників датчиків через HTTP-запити.

---

## 🛠 Апаратне та програмне забезпечення

* **Мікроконтролер**: Wemos D1 mini (ESP8266)
* **Датчик температури/вологості**: DHT11 (підключений до пін `D7`)
* **Дисплей**: LCD 1602 з I2C-адаптером (піни `D1` / SCL, `D2` / SDA)
* **Середовище розробки**: VS Code + PlatformIO
* **Фреймворк**: Arduino

### Залежності (`platformio.ini`)
* `ESP8266WiFi` (стандартна бібліотека)
* `ESP8266WebServer` (стандартна бібліотека)
* `DHT sensor library` (автор: Adafruit)
* `LiquidCrystal_I2C` (автор: Marco Schwartz)
